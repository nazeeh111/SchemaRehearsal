Method, privacy and limits

Each scenario starts with its own fresh copies of the same database snapshot. The same steps run before and after migration. Comparisons preserve value types, values and duplicate rows, using each observation’s declared ordering.

Schema differences provide context. Passing integrity and foreign-key checks does not establish unchanged application behavior.

Only declared scenarios were examined. A match is not a guarantee about other workloads, database versions, production concurrency or malicious input.

This report omits the database snapshot, SQL, bound parameters, source paths, raw result cells and raw SQLite error messages. Scenario, observation and schema names, shapes and hashes remain visible metadata. Retain original input files privately.
