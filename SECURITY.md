# Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/nazeeh111/SchemaRehearsal/security/advisories/new) for a suspected source-write, unauthorized file-access or data-disclosure defect. Include a small synthetic reproducer, Python/SQLite versions and the affected release. Do not attach a private application database or credentials.

SchemaRehearsal is a local rehearsal tool with a SQLite authorizer and cooperative workload bounds. It is not an operating-system sandbox or a migration-safety certification. Only the latest release is maintained; there is no guaranteed response time. See the README for supported inputs and retained report metadata.
